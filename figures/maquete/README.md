# Maquete da primeira tela

Figura isométrica feita com o kit da skill [Anatomy](https://github.com/wheresryan22/anatomy) (MIT, cópia em `kit/`, commit 1482e84).

- `build.mjs` desenha a maquete e escreve `src/components/maquete/maquete.svg`.
- `src/components/maquete/tema.css` pinta a figura com as cores de `global.css`.
- `src/components/HeroFilme.astro` faz o movimento (um script pequeno, sem biblioteca).

Depois de mudar o desenho, rode `node figures/maquete/build.mjs` e depois `npm run build`.
